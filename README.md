# Netflix Data Analysis and Visualization

A Python-based data analysis and visualization project using the Netflix dataset.  
The project explores Netflix content using **Pandas** for data processing and **Matplotlib** for visualization.

## Project Overview

This project analyzes a Netflix dataset to understand the distribution and characteristics of movies and TV shows available on the platform.

The analysis includes:

- Number of Movies vs TV Shows
- Distribution of Movie Durations
- Top 10 Countries by Number of Shows
- Percentage Distribution of Content Ratings
- Basic data cleaning and preprocessing

## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code
- Git
- GitHub

The project uses a Netflix dataset containing information about Netflix titles, including:
